# LUZHRA1 Preview Assets

Public, versioned illustrations for the LUZHRA1 Salla Twilight theme.

- Release tag for the first hosted set: `1.0.15` (matches the theme package version).
- GitHub Pages deploys the `site/` directory when a version tag is pushed.
- Preview URL root: `https://azpc1993.github.io/LUZHRA1-preview-assets/1.0.15/images/`
- Component-to-file mapping: [`site/component-preview-map.csv`](site/component-preview-map.csv).

The theme manifest must use full HTTPS image URLs. Each image has its own stable versioned path so later releases do not change earlier preview assets.
